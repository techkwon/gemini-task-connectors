이제 제미나이가 캔바, 카훗, 노션, 패들렛을 마음대로 조종한다그런데 한국은 무료라고?

제미나이 웹의 '태스크(Task)' 모드에 커스텀 커넥터(MCP)를 연결하고 @로 부르면, 한 번의 요청으로 캔바 발표 자료·카훗 퀴즈·패들렛 보드·노션 지도안을 실제로 만들어 줘요.

Line 01

한국은 무료?

발표 내용만 그대로 옮겼어요. 확인하지 못한 부분은 확인하지 못했다고 적었어요.

태스크(Task)는 6개 나라에 무료로 풀려요

구글 코리아 블로그에 따르면 제미나이의 태스크 기능이 아래 6개 나라 사용자에게 무료로 순차 제공돼요.

  • 미국
  • 한국
  • 일본
  • 캐나다
  • 호주
  • 인도
  • 가게에 전화로 문의해 주는 기능과 Google Pay 결제는 미국에서만 돼요.

출처: 구글 코리아 블로그 · 영어 보도 TechRepublic

솔직하게 적어 둘게요

태스크가 무료인 것과 별개로, 커스텀 커넥터까지 무료 계정에서 되는지는 직접 확인하지 못했어요.

커스텀 커넥터 조건은 구글 도움말을 먼저 확인해 주세요.

support.google.com/gemini/answer/17209137

Line 02

연결하는 법

한 번만 연결해 두면 다음부터는 @로 부르기만 하면 돼요. 화면은 2026-11-23 기준이에요.

  1. 입력창 아래에서 Chat → Task로 바꿔요

    gemini.google.com에 들어가면 입력창 바로 아래에 Chat · Task 전환 버튼이 있어요. Task를 눌러요.

  2. 설정 → 커넥터(Connectors) 화면에서 「+ Custom」

    설정에서 커넥터 화면으로 가면 Discover · Connectors · Skills 탭이 보여요. 오른쪽 위 + Custom을 눌러요.

  3. 「Connect to an MCP server」에 주소 붙여넣기

    아래 커넥터 표에서 주소를 복사해 MCP Server URL 칸에 붙여 넣어요.

    이때 구글이 검토하지 않은 앱이라는 경고가 나와요. 믿을 수 있는 서비스 주소인지 꼭 확인하세요.

  4. 서비스 로그인·권한 허용 뒤 Custom apps에 보여요

    각 서비스(캔바, 카훗, 패들렛, 노션…)의 로그인 창이 뜨면 로그인하고 권한을 허용해요(OAuth). 끝나면 커넥터 목록 아래쪽 Custom apps에 나타나요.

  5. 커넥터 상세: 동작마다 승인 방식을 정해요

    커넥터를 누르면 동작(App actions)이 읽기와 쓰기·삭제로 나뉘어 있고, 동작마다 승인 방식을 고를 수 있어요. 기본값은 Always ask(매번 묻기)예요.

  6. Task 입력창에서 @ → 이름 입력 → 목록에서 고르기

    @를 누르고 이름을 조금 치면 Connectors 목록이 떠요. 여기서 골라야 입력창에 칩으로 들어가요.

글자로 「@Canva MCP」라고만 쓰면 연결이 안 돼요

프롬프트에 @Canva MCP처럼 글자만 적으면 제미나이는 커넥터를 부르지 않아요. 반드시 @를 누르고 목록에서 골라 칩으로 넣어야 해요.

“현재 Canva, Kahoot, Padlet, Notion 연동 기능이 연결되어 있지 않아…” 첫 시도(글자로만 적었을 때) 제미나이의 답

Line 04

실제로 돌려 봤다

Task 모드에서 칩 4개를 넣고 아래 프롬프트 하나만 보냈어요. 중학교 1학년 과학 「물의 순환」 1차시 수업 준비예요.

보낸 프롬프트 그대로
@Canva MCP Server @Kahoot MCP Server @Padlet MCP Server @Notion MCP 
이 네 앱으로 중학교 1학년 과학 '물의 순환' 1차시(45분) 수업을 준비해 줘.
1) Canva: 수업용 발표 자료 8장 (도입 질문, 증발, 응결, 강수, 지표수·지하수 흐름, 순환 전체 그림, 생활 속 예, 정리)
2) Kahoot: 정리용 4지선다 퀴즈 8문항
3) Padlet: 학생들이 '우리 주변 물의 순환 사례'를 올리는 보드 (섹션: 증발, 응결, 강수, 흐름)
4) Notion: 수업 지도안 페이지 (학습 목표, 45분 흐름 표, 위 자료 링크 포함)
마지막에 만든 4개의 링크를 정리해 줘.

복사 버튼은 글자만 복사해요. 칩 4개는 입력창에서 @를 눌러 직접 넣어 주세요.

    Line 05

    쓰기 전에 꼭

    편하지만, 내 계정의 앱을 AI가 직접 만지는 일이에요. 다섯 가지만 지켜 주세요.

    • 학생 개인정보는 넣지 않아요이름·번호·성적처럼 학생을 알아볼 수 있는 정보는 프롬프트에도, 만들어질 자료에도 넣지 마세요.
    • 「Always allow」는 읽기 동작에만승인 클릭이 번거로워도 쓰기·삭제 동작은 「Always ask」로 두는 게 안전해요.
    • 받은 링크는 편집용이에요학생에게 공유하기 전에 각 서비스의 공유 설정(보기 전용, 로그인 필요 여부)을 확인하세요.
    • 결과물은 사람이 검토해요이번에도 빠진 슬라이드, 어긋난 슬라이드 번호, 그림 속 깨진 글자가 나왔어요. 수업 전에 꼭 한 번 훑어보세요.
    • 구글이 검토하지 않은 커스텀 앱이에요연결할 때 경고가 뜨는 이유예요. 공식 서비스 주소인지 확인하고, 안 쓰는 커넥터는 연결을 끊어 두세요.
